# Jignesh Datta — Developer Portfolio

A responsive, dark-themed developer portfolio built with plain HTML, CSS and JavaScript. No build tools or paid theme required.

## Files
- `index.html` — page content and project sections
- `styles.css` — responsive styling
- `script.js` — mobile navigation and current year
- `assets/` — add your own approved project screenshots here

## Preview locally
1. Extract the ZIP.
2. Open `index.html` in a browser.
3. For a local server, run `python3 -m http.server 8000` from this folder and visit `http://localhost:8000`.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a public repository named `yourusername.github.io`.
3. Upload `index.html`, `styles.css`, `script.js`, and the `assets` folder to the repository root.
4. In repository Settings → Pages, select deploy from the `main` branch and root folder.
5. Your site will be available at `https://yourusername.github.io`.

Cloudflare Pages is another free static-hosting option. Connect the GitHub repository and use the root directory; no build command is needed.

## Before publishing — personalize these items
Search and replace:
- `YOUR_EMAIL@example.com` with your professional email address.
- `YOUR-LINKEDIN` with your LinkedIn profile slug.
- Add your GitHub URL if you want it shown.
- Update earlier career details from your complete CV.
- Add approved public project URLs and screenshots only where client confidentiality permits.
- Confirm that each project description accurately reflects your own contribution.
- Add a downloadable PDF CV link if desired.

## Contact form
The contact button currently opens the visitor's email app using a `mailto:` link. This avoids exposing a third-party form service or requiring a backend. To use a web form, connect a form provider or build a secure backend endpoint and add spam protection.

## Notes
The project artwork is CSS-based placeholder artwork, not official client screenshots or endorsements. Replace it only with images you own or have permission to publish. The site intentionally avoids fabricated metrics, client testimonials and project outcomes.
